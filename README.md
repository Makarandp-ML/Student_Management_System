# Student Management System

## Overview

A desktop application developed using Python, Tkinter and SQLite to manage student records.

## Features

- Add Student
- View Students
- Update Student
- Delete Student
- Search Student
- Email Validation
- Phone Validation
- SQLite Database
- Scrollable Table

## Technologies

- Python
- Tkinter
- SQLite3

## Project Structure

Student_Management_System/
│
├── database/
│ └── student.db
│
├── src/
│ ├── database.py
│ ├── gui.py
│ └── main.py

## Run

```bash
python src/main.py
```
