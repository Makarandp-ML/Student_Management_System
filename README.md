# Student Management System

A desktop-based Student Management System built using Python, Tkinter, and SQLite.

## Features

- Add Student
- Update Student
- Delete Student
- Search Student
- View All Students
- Input Validation
- SQLite Database
- User-friendly GUI

## Technologies Used

- Python 3
- Tkinter
- SQLite3

## Project Structure

```
Student_Management_System/
│── database/
│   └── student.db
│── src/
│   ├── main.py
│   ├── gui.py
│   └── database.py
│── README.md

```

## How to Run

```bash
python src/main.py
```
